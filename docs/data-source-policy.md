# Data Source Policy

ScoutBoard AI starts with self-created synthetic data only.

Rules for this repo:

- Do not commit private job-search files, resumes, CrowdWorks messages, Telegram logs, or screenshots with personal information.
- Do not commit scraped football data unless the source license and terms clearly allow reuse.
- Mark synthetic records clearly when they are used to demonstrate validation behavior.
- Keep source URL, source name, and last checked date on every research-facing claim.
- Keep unsupported AI-generated statements out of final reports.

Future open-data additions must include attribution notes in this file before they are committed.
